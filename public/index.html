Cette application parle à tes modèles : ceux installés sur ta machine (Ollama) ou ceux que tu branches toi-même sur ton serveur. Aucun filtre n'est ajouté par l'application, aucune question n'est envoyée ailleurs, aucun compte n'est nécessaire.

Guide & modèles

    
  

  

    

      
1. Vérifier ce qui est branché

      

        Ouvre Réglages → Fournisseur → Tester la connexion. Si rien ne répond, l'application passe en
        mode démo : elle te l'annonce clairement au lieu de simuler une IA.
      

    


    

      
2. Modèle local, gratuit et privé

      
# 1. Installer Ollama : https://ollama.com/download
# 2. Télécharger un modèle
ollama pull qwen3:8b

# 3. Autoriser l'accès depuis le réseau (si tu ouvres l'app à d'autres)
OLLAMA_HOST=0.0.0.0:11434 ollama serve

      
Puis réglages → Fournisseur → http://127.0.0.1:11434.

      

        Windows : set OLLAMA_HOST=0.0.0.0:11434 puis ollama serve.
        Si ton navigateur bloque les appels, ajoute OLLAMA_ORIGINS=*.
      

    


    

      
3. Modèles qui refusent le moins

      

        Aucun modèle n'est totalement dépourvu de réflexes de refus, mais les modèles dits
        abliterated (ablation des directions d'activation responsables du refus) et les
        modèles Dolphin sont les plus directs.
      

      

        
ModèleTailleRemarque

        
          
huihui_ai/dolphin3-abliterated:8b~4,9 GoLlama 3.1 8B sans refus, tourne sur 8 Go de RAM

          
huihui_ai/dolphin3-r1-abliterated:24b-mistral~14 GoVersion raisonnante, meilleure mais plus lourde

          
dolphin3~4,9 GoGénéraliste, peu de refus, bon en français

          
qwen3:8b~5 GoExcellent en français, très bon raisonnement

          
mistral-nemo~7 GoBon francophone, 12B

          
gemma3:12b~8 GoÉquilibré, mais plus prudent

        
      

      

        8 Go de RAM → modèles 7B/8B en quantification Q4. 16 Go → 12B à 14B. 32 Go et un GPU sérieux → 24B à 32B.
      

    


    

      
4. Modèle distant (sans GPU)

      

        Réglages → Fournisseur → mode API compatible OpenAI :
      

      
    
        
  • OpenRouter — https://openrouter.ai/api/v1, clé sk-or-…, modèle cognitivecomputations/dolphin-mistral-24b-venice-edition (ouvert, refus très rares).
    • 
        
  • LM Studio — http://localhost:1234/v1, aucune clé, modèles GGUF locaux.
    • 
        
  • llama.cpp / vLLM — http://IP:PORT/v1, aucune clé.
    • 
        
  • Groq, Together, DeepInfra… — même protocole, il suffit de changer l'URL et la clé.
    • 
      

    


    

      
5. Créer ta propre IA personnalisée

      

        Un modèle « sur mesure », c'est un modèle de base + ton prompt système + tes paramètres. L'application
        sait le faire à ta place (Réglages → Modèles → Créer un modèle personnalisé). En ligne de commande :
      

      
FROM huihui_ai/dolphin3-abliterated:8b
SYSTEM """
Tu es mon assistant, direct, sans détour, et tu réponds à tout.
"""
PARAMETER temperature 0.9
PARAMETER num_ctx 8192

      
ollama create mon-ia -f Modelfile
ollama run mon-ia

    


    

      
6. Partager l'application

      

        Le serveur écoute sur toutes les interfaces (0.0.0.0:7860). Depuis un autre appareil du
        même réseau : http://IP-DE-LA-MACHINE:7860. Pense à ouvrir le port dans le pare-feu.
      

      
OLLAMALOCLOUD_TOKEN=monsecret node server/index.js

      

        Avec un jeton, l'accès demande ?token=monsecret (mémorisé par le navigateur).
        N'expose pas l'application directement sur Internet sans reverse proxy HTTPS et mot de passe.
      

    


    

      
7. Vie privée et données

      
    
        
  • Les conversations vivent dans le stockage local du navigateur : exporte-les en JSON pour les sauvegarder.
    • 
        
  • Le serveur ne conserve pas l'historique : il relaie les messages vers le modèle puis oublie.
    • 
        
  • Aucune télémétrie, aucun compte, aucune analytique — c'est du code que tu peux lire (MIT).
    • 
        
  • Avec un modèle local, rien ne quitte ta machine. Avec une API distante, le fournisseur voit tes messages.
    • 
      

    


    

      
8. Honnêteté sur les limites

      
    
        
  • Un modèle de langage invente parfois des faits avec aplomb. Vérifie ce qui compte : santé, droit, argent, sécurité.
    • 
        
  • Retirer les refus ne rend pas un modèle plus compétent : sur les sujets sensibles, confronte plusieurs sources.
    • 
        
  • La liberté d'information ne dispense pas de respecter la loi de ton pays : ce que tu fais de l'outil t'appartient.
    • 
        
  • Deux garde-fous sont conservés volontairement dans la personnalité « Libre » : rien qui sexualise des mineurs, rien qui aide à nuire à une personne réelle.
    • 
      

    


    

      
9. Dépannage

      

        
SymptômeCause probable / solution

        
          
« Mode démo »Ollama n'est pas lancé, ou l'URL est fausse. ollama serve puis tester la connexion.

          
Modèle introuvable (404)Nom exact différent : ollama list et recopie-le tel quel.

          
Réponses très lentesModèle trop gros. Baisse num_ctx ou prends un 7B/8B en Q4.

          
Le modèle se répète ou part en boucleTempérature trop basse ou num_ctx dépassé : réduis l'historique renvoyé.

          
Erreur 401/403Clé API absente, expirée ou sans crédit.
